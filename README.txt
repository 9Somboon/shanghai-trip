# 🌐 โฟลเดอร์นี้พร้อมอัปขึ้น Netlify Drop (ฉบับการจองจริง v3)

## วิธีขึ้นเว็บ
### ทางเลือก 1: Netlify Drop (30 วินาที)
1. แตก zip → ได้โฟลเดอร์ netlify_site
2. เปิด https://app.netlify.com/drop
3. ลากโฟลเดอร์ netlify_site (หรือไฟล์ zip นี้) ไปวาง
4. รอ ~10 วินาที → ได้ลิงก์ https://xxx.netlify.app ส่งเข้ากลุ่ม LINE ได้เลย
5. (แนะนำ) สมัคร Netlify ฟรี → Site settings → Change site name เป็น shanghai-trip-dec2026

### ทางเลือก 2: GitHub Pages
โฟลเดอร์นี้มี index.html ที่ root แล้ว → push ทั้งโฟลเดอร์ขึ้น branch main ของ repo แล้วเปิด Settings → Pages → Deploy from branch → main / (root) ได้เลย
